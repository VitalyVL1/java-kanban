# Менеджер задач (Task Manager)

## О проекте

Консольное приложение для управления задачами, разработанное в рамках учебного курса **"Java-разработчик. Расширенный"**
от **Яндекс Практикум**. Это первый проект, демонстрирующий основы объектно-ориентированного программирования на Java,
работу с коллекциями, обработку исключений и файловый ввод/вывод.

## Функциональность

Приложение позволяет управлять тремя типами задач:

- **Task** (обычная задача) - простая задача с названием, описанием, статусом и временными параметрами
- **Epic** (эпик) - составная задача, объединяющая несколько подзадач
- **Subtask** (подзадача) - задача, входящая в состав эпика

### Основные возможности:

- ✅ Создание, чтение, обновление и удаление задач всех типов
- ✅ Автоматическое обновление статуса эпика на основе статусов его подзадач
- ✅ Проверка пересечения задач по времени выполнения
- ✅ Сортировка задач по приоритету (времени начала)
- ✅ История просмотров последних 10 задач
- ✅ Автоматическое сохранение состояния в файл
- ✅ Восстановление состояния из файла при запуске

## Технологический стек

- **Java 17** - язык программирования
- **Gson** - библиотека для сериализации/десериализации JSON
- **JUnit 5** - модульное тестирование

## Архитектура проекта

### Ключевые компоненты:

#### Модели (`model`)

- `Task` - базовый класс для всех задач
- `Epic` - эпик (наследник Task)
- `Subtask` - подзадача (наследник Task)
- `TaskStatus` - статус задачи (NEW, IN_PROGRESS, DONE)
- `TaskType` - тип задачи (TASK, EPIC, SUBTASK)

#### Менеджеры (`manager`)

- `TaskManager` - интерфейс менеджера задач
- `InMemoryTaskManager` - реализация в оперативной памяти
- `FileBackedTaskManager` - реализация с автосохранением в файл
- `HistoryManager` - интерфейс менеджера истории
- `InMemoryHistoryManager` - реализация истории с двусвязным списком
- `Managers` - фабрика для создания менеджеров

#### Исключения (`exception`)

- `NotFoundException` - задача не найдена
- `TaskOverlappingException` - пересечение времени задач
- `ManagerSaveException` - ошибка сохранения/загрузки

#### HTTP API (`api`)

- **Адаптеры Gson** для корректной сериализации типов Java Time
    - `DurationAdapter` - преобразование Duration в минуты
    - `LocalDateTimeAdapter` - преобразование даты в формат "dd-MM-yyyy HH:mm:ss.SSS"
- **HTTP-сервер** (`HttpTaskServer`) на порту 8080
- **Базовый обработчик** (`BaseHttpHandler`) с методами для отправки ответов
- **Обработчик задач** (`TaskHttpHandler`) - реализация всех эндпоинтов

## API Endpoints

### GET запросы

| Эндпоинт               | Описание                      | Код ответа             |
|------------------------|-------------------------------|------------------------|
| `/tasks`               | Получить все задачи           | 200 OK                 |
| `/tasks/{id}`          | Получить задачу по ID         | 200 OK / 404 Not Found |
| `/epics`               | Получить все эпики            | 200 OK                 |
| `/epics/{id}`          | Получить эпик по ID           | 200 OK / 404 Not Found |
| `/epics/{id}/subtasks` | Получить подзадачи эпика      | 200 OK / 404 Not Found |
| `/subtasks`            | Получить все подзадачи        | 200 OK                 |
| `/subtasks/{id}`       | Получить подзадачу по ID      | 200 OK / 404 Not Found |
| `/history`             | Получить историю просмотров   | 200 OK                 |
| `/prioritized`         | Получить задачи по приоритету | 200 OK                 |

### POST запросы

| Эндпоинт         | Описание                        | Код ответа                                 |
|------------------|---------------------------------|--------------------------------------------|
| `/tasks`         | Создать новую задачу            | 201 Created / 406 Conflict / 500 Error     |
| `/tasks/{id}`    | Обновить существующую задачу    | 201 Created / 404 Not Found / 406 Conflict |
| `/epics`         | Создать новый эпик              | 201 Created / 500 Error                    |
| `/epics/{id}`    | Обновить существующий эпик      | 201 Created / 404 Not Found                |
| `/subtasks`      | Создать новую подзадачу         | 201 Created / 404 Not Found / 406 Conflict |
| `/subtasks/{id}` | Обновить существующую подзадачу | 201 Created / 404 Not Found / 406 Conflict |

### DELETE запросы

| Эндпоинт         | Описание                | Код ответа |
|------------------|-------------------------|------------|
| `/tasks`         | Удалить все задачи      | 200 OK     |
| `/tasks/{id}`    | Удалить задачу по ID    | 200 OK     |
| `/epics`         | Удалить все эпики       | 200 OK     |
| `/epics/{id}`    | Удалить эпик по ID      | 200 OK     |
| `/subtasks`      | Удалить все подзадачи   | 200 OK     |
| `/subtasks/{id}` | Удалить подзадачу по ID | 200 OK     |

## Формат данных

### JSON представление задачи

```json
{
  "id": 1,
  "title": "Купить продукты",
  "description": "Молоко, хлеб, яйца",
  "status": "NEW",
  "type": "TASK",
  "duration": 3600000,
  "startTime": "15-03-2024 14:30:00.000"
}
```

### Формат времени

- Дата и время: dd-MM-yyyy HH:mm:ss.SSS

- Длительность: в миллисекундах (для JSON) или минутах (для файла)

### Формат файла сохранения (CSV)
```text
id,type,name,status,description,epic,startTime,duration
1,TASK,Купить продукты,NEW,Молоко хлеб,,1640995200000,3600000
2,EPIC,Переезд,NEW,Подготовка к переезду,,,
3,SUBTASK,Упаковка вещей,NEW,Коробки,,1641081600000,1800000,2
```

## Требования
- Java 17 или выше

## Особенности реализации
- История просмотров реализована через кастомный двусвязный список + HashMap для доступа за O(1)

- Проверка пересечений выполняется при добавлении и обновлении задач

- Защитные копии - методы возвращают копии объектов, предотвращая внешние модификации

- Автосохранение - FileBackedTaskManager сохраняет состояние после каждого изменения

- Адаптеры Gson - обеспечивают корректную сериализацию Duration и LocalDateTime

## Тестирование
- Проект покрыт модульными тестами с использованием JUnit 5. Тесты находятся в директории test/ и покрывают:
- Все методы менеджеров задач
- Обработку исключений
- Корректность сохранения и загрузки из файла
- HTTP обработчики
- Проверку пересечений времени
- Работу истории просмотров
